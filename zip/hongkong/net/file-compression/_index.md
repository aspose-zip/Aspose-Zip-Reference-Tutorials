## 如何在 .NET 中建立無壓縮的 Zip 檔案？

`ZipArchive` 是代表 zip 容器的類別，提供建立、讀取與修改 zip 檔案的方法。  
`CompressionMethod` 決定條目的儲存方式；`Store` 選項會在不壓縮的情況下儲存資料。

將檔案載入 `ZipArchive` 實例，將每個條目的 `CompressionMethod` 設為 `Store`，然後儲存封存——這就是完整的「無壓縮 zip 檔案」工作流程，只需三個簡潔步驟。此方式可保持原始檔案大小不變，同時提供單一可攜帶的容器，便於高效傳輸或儲存。

## 常見問題

**Q: Can I use Aspose.Zip to create a zip archive .net on .NET Core?**  
**A:** 絕對可以。Aspose.Zip 完全支援 .NET Core 2.0–3.1，以及 .NET 5–10。

**Q: How do I modify an existing archive without extracting it first?**  
**A:** 使用 “modify zip file c#” API，即可直接在封存串流上新增、刪除或重新命名條目，無需先解壓。

**Q: Which compression method gives the best ratio for text files?**  
**A:** 通常 Bzip2 或 LZMA 能為文字檔提供較高的壓縮率，但相較於 Deflate 速度較慢。建議兩者皆測試，以找出最適合的平衡點。

**Q: Is there a way to encrypt files while creating the zip archive?**  
**A:** 有，Aspose.Zip 支援 AES 加密。您可在儲存 ZipArchive 之前為其設定密碼。

**Q: Do I need to worry about file name encoding?**  
**A:** Aspose.Zip 會自動處理 Unicode 檔名，若需與舊系統相容，也可自行設定編碼。

**Q: Can I add files to an existing zip without recreating it?**  
**A:** 可以，API 提供 **add files zip .net** 方法，讓您直接在現有封存中加入新條目。

**Q: Does Aspose.Zip support streaming large files?**  
**A:** 支援。您可使用串流方式處理大型檔案，避免一次將整個檔案載入記憶體，特別適合大規模情境。
