## Γρήγορες απαντήσεις
- **Τι κάνει το Aspose.Zip;** Δημιουργεί, συμπιέζει και εξάγει αρχεία ZIP σε καθαρό κώδικα .NET χωρίς εξωτερικά εργαλεία.

- **Πόσο μεγάλο αρχείο μπορεί να διαχειριστεί το Aspose.Zip;** Μπορεί να επεξεργαστεί έως 5 GB χωρίς να φορτώνει ολόκληρο το αρχείο στη μνήμη.  
- **Υποστηρίζει η βιβλιοθήκη .NET 5/6/7;** Υποστηρίζεται πλήρως σε .NET Framework 2.0‑4.8.1, .NET Core 2.0‑3.1 και .NET 5‑10.

## Τι σημαίνει “εξαγωγή αρχείων zip με το Aspose.Zip”;
Η εξαγωγή αρχείων zip με το Aspose.Zip σημαίνει την αποσυμπίεση ενός αρχείου `.zip` πίσω στην αρχική του δομή φακέλων και αρχείων χρησιμοποιώντας το API του Aspose.Zip. Η λειτουργία εκτελείται εξ ολοκλήρου σε διαχειριζόμενο κώδικα .NET, εξαλείφοντας την ανάγκη για εγγενείς DLL ή εξωτερικά εργαλεία, και υποστηρίζει εξαγωγή μέσω ροής (streaming) για να διατηρεί τη χρήση μνήμης χαμηλή ενώ διατηρεί τις χρονικές σφραγίδες και τα χαρακτηριστικά των αρχείων.

## Γιατί να χρησιμοποιήσετε το Aspose.Zip για .NET;
Το Aspose.Zip μπορεί να **επεξεργαστεί αρχεία έως 5 GB** διατηρώντας τη χρήση μνήμης κάτω από 100 MB χάρη στην αρχιτεκτονική ροής του. Υποστηρίζει **30+ επίπεδα συμπίεσης**, παρέχοντας λεπτομερή έλεγχο της ταχύτητας σε σχέση με το μέγεθος. ## Πώς να εξάγετε αρχεία zip με το Aspose.Zip
`ZipFile` είναι η κύρια κλάση που αντιπροσωπεύει ένα αρχείο ZIP στο Aspose.Zip. Για να εξάγετε ένα ZIP, δημιουργήστε μια παρουσία `ZipFile` που δείχνει στο αρχείο του αρχείου, προαιρετικά ορίστε την ιδιότητα `Password` για κρυπτογραφημένα αρχεία, και στη συνέχεια καλέστε το `ExtractAll("outputFolder")`. Η μέθοδος αναδημιουργεί την αρχική ιεραρχία φακέλων, επικυρώνει κάθε καταχώρηση και επιστρέφει μια σημαία κατάστασης που υποδεικνύει επιτυχία ή αποτυχία.

### Διαχείριση αρχείων zip προστατευμένων με κωδικό
Αν το αρχείο είναι ασφαλισμένο, ορίστε τον κωδικό πριν από την εξαγωγή.  
**Άμεση απάντηση:** Ορίστε `zip.Password = "yourPassword"` και στη συνέχεια καλέστε `zip.ExtractAll(...)`. Το Aspose.Zip αποκρυπτογραφεί κάθε καταχώρηση άμεσα, έτσι δεν χρειάζεται ποτέ να αποθηκεύσετε τα μη κρυπτογραφημένα δεδομένα στο δίσκο.

### Κρυπτογράφηση αρχείου zip κατά την εξαγωγή (επανακρυπτογράφηση)
Σε ασφαλή περιβάλλοντα μπορεί να χρειαστεί να εξάγετε και άμεσα να επανακρυπτογραφήσετε το περιεχόμενο.  
**Άμεση απάντηση:** Μετά την εξαγωγή μιας καταχώρησης σε ροή, δημιουργήστε μια νέα παρουσία `ZipFile`, προσθέστε τη ροή ως νέα καταχώρηση και ορίστε τις ιδιότητες `EncryptionAlgorithm` και `Password` πριν αποθηκεύσετε το νέο αρχείο. Αυτό διατηρεί τα δεδομένα κρυπτογραφημένα καθ' όλη τη διάρκεια της διαδικασίας.

### Συμπίεση πολλαπλών αρχείων – σύντομη ανασκόπηση
Παρόλο που αυτό το σεμινάριο εστιάζει στην εξαγωγή, το Aspose.Zip διαπρέπει επίσης στην **συμπίεση πολλαπλών αρχείων .net**. Μπορείτε να προσθέσετε δεκάδες αρχεία με μία κλήση, να επιλέξετε οποιοδήποτε από τα 30+ επίπεδα συμπίεσης, και ακόμη να χωρίσετε τα αρχεία σε τόμους για ευκολότερη μεταφορά.

## Συχνά προβλήματα & λύσεις
- **Η εξαγωγή αποτυγχάνει με “Invalid password”.** Επαληθεύστε τον ακριβή κωδικό που χρησιμοποιήθηκε κατά τη συμπίεση· οι κωδικοί είναι ευαίσθητοι σε πεζά/κεφαλαία.  
- **OutOfMemoryException σε μεγάλα αρχεία.** Μεταβείτε στο streaming API (`ExtractToStream`) για να επεξεργάζεστε τις καταχωρήσεις μία τη φορά αντί να φορτώνετε ολόκληρο το αρχείο.  
- **Σύγκρουση ονομάτων αρχείων.** Ενεργοποιήστε τη σημαία `OverwriteExistingFiles` ή διαχειριστείτε το συμβάν `FileExists` για να μετονομάζετε αυτόματα τα συγκρουόμενα αρχεία.

## Συχνές ερωτήσεις

**Q: Μπορώ να εξάγω ένα αρχείο zip χωρίς να γνωρίζω τον κωδικό του;**  
A: Όχι, το Aspose.Zip απαιτεί τον σωστό κωδικό για να αποκρυπτογραφήσει ένα αρχείο προστατευμένο με κωδικό. Μπορείτε να πιάσετε το `InvalidPasswordException` για να διαχειριστείτε λανθασμένους κωδικούς με χάρη.

**Q: Υποστηρίζει το Aspose.Zip άλλες μορφές αρχείων όπως RAR ή 7z;**  
A: Η άμεση υποστήριξη περιορίζεται στο ZIP, αλλά μπορείτε να συνδυάσετε το Aspose.Zip με βιβλιοθήκες τρίτων για αυτές τις μορφές, ή να χρησιμοποιήσετε το σεμινάριο “Archive Extraction and Formats” για καθοδήγηση.

**Q: Πώς μπορώ να εξάγω μόνο συγκεκριμένα αρχεία από ένα μεγάλο αρχείο;**  
A: Χρησιμοποιήστε τη μέθοδο `ExtractEntry` για να στοχεύσετε μεμονωμένες καταχωρήσεις με βάση το όνομα, αποφεύγοντας την ανάγκη εξαγωγής ολόκληρου του αρχείου.

**Q: Υπάρχει τρόπος να παρακολουθήσω την πρόοδο της εξαγωγής;**  
A: Ναι—εγγραφείτε στο συμβάν `ProgressChanged` του αντικειμένου `ZipFile` για να λαμβάνετε ενημερώσεις σε πραγματικό χρόνο. Το `ProgressChanged` ενεργοποιείται περιοδικά με πληροφορίες προόδου εξαγωγής.

**Q: Ποια άδεια απαιτείται για εμπορική χρήση;**  
A: Απαιτείται πληρωμένη άδεια Aspose.Zip για παραγωγικές εγκαταστάσεις· διατίθεται δωρεάν άδεια αξιολόγησης για δοκιμές.
