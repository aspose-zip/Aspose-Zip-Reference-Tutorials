## Βήμα 2: Άνοιγμα GZip Archive (Εξαγωγή αρχείου gzip C#)

`GgzipArchive` είναι η κλάση του Aspose.Zip που αντιπροσωπεύει ένα μοναδικό αρχείο GZIP και παρέχει εξαγωγή βασισμένη σε ροή.

```csharp
//ExStart: OpenGZipArchive
//Extracts the archive and copies extracted content to file stream.
using (var archive = new GzipArchive(dataDir + "archive.gz"))
{
    using (var extracted = File.Create(dataDir + "data.bin"))
    {
        var unpacked = archive.Open();
        byte[] b = new byte[8192];
        int bytesRead;
        while (0 < (bytesRead = unpacked.Read(b, 0, b.Length)))
            extracted.Write(b, 0, bytesRead);
    }
}
//ExEnd: OpenGZipArchive
Console.WriteLine("Successfully Opened GZip Archive");
```

Αυτός ο κώδικας δείχνει πώς να **εξάγετε ένα αρχείο gzip σε C#** χρησιμοποιώντας το Aspose.Zip. Το αρχείο συμπιέσεως ανοίγει, τα περιεχόμενά του μεταδίδονται μέσω ροής, και το αποτέλεσμα γράφεται στο `data.bin`.
