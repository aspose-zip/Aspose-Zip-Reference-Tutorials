## Τι είναι το Aspose.Zip for .NET;

`Aspose.Zip for .NET` είναι ένα καθαρά διαχειριζόμενο .NET στοιχείο που δημιουργεί, εξάγει και χειρίζεται αρχεία ZIP, SevenZip, RAR, TAR και άλλες μορφές αρχείων χωρίς καμία εγγενή εξάρτηση. Λειτουργεί με ροές, μνήμες buffer και αποθήκευση στο cloud, καθιστώντας το ιδανικό για υπηρεσίες web υψηλής απόδοσης και αρχιτεκτονικές μικρο‑υπηρεσιών.

## Γιατί να χρησιμοποιήσετε αυτή τη zip library for .net;

Το Aspose.Zip υποστηρίζει **30+ compression algorithms** και **12 archive formats**, και μπορεί να επεξεργαστεί αρχεία έως **10 GB** μέσω της αρχιτεκτονικής ροής. Η βιβλιοθήκη λειτουργεί σε **.NET Framework 4.6+**, **.NET Core 3.1+**, και **.NET 5/6/7**, παρέχοντας την ίδια συμπεριφορά σε Windows, Linux και macOS.

## Πώς να δημιουργήσετε αρχείο zip .net με Aspose.Zip;

`ZipArchive` είναι η κύρια κλάση που αντιπροσωπεύει ένα αρχείο ZIP στο Aspose.Zip. Φορτώστε τα αρχεία προέλευσης, δημιουργήστε ένα αντικείμενο `ZipArchive`, προσθέστε κάθε καταχώρηση και καλέστε `Save` σε μια ροή-στόχο. Αυτό το μοτίβο δημιουργεί το αρχείο σε μία μόνο διέλευση, διατηρώντας τη χρήση μνήμης κάτω από 50 MB ακόμη και για πακέτα πολλαπλών gigabyte. `CreateArchive(Stream)` δημιουργεί ένα νέο αρχείο και γράφει απευθείας στη δοθείσα ροή, επιτρέποντας επεξεργασία με χαμηλή μνήμη. Χρησιμοποιήστε την υπερφόρτωση `CreateArchive(Stream)` για να γράψετε απευθείας σε `HttpResponse` για λήψεις εν κινήσει.
