## Πώς να δημιουργήσετε zip με κωδικό πρόσβασης σε .NET;

Φορτώστε τον φάκελο προορισμού, δημιουργήστε ένα αντικείμενο `ZipFile`, προσθέστε κάθε αρχείο με τον δικό του κωδικό πρόσβασης και, τέλος, καλέστε `Save` για να γράψετε το αρχείο. Όλη αυτή η διαδικασία απαιτεί μόνο λίγες γραμμές κώδικα και εγγυάται ότι κάθε καταχώρηση κρυπτογραφείται με τον κωδικό πρόσβασης που καθορίζετε.

### Βήμα 1: ορίστε τη διαδρομή του καταλόγου πόρων

Ορίστε τη διαδρομή του καταλόγου πόρων όπου βρίσκονται τα αρχεία σας.

```csharp
string dataDir = "Your Document Directory";
```

### Βήμα 2: συμπιέστε αρχεία με ξεχωριστούς κωδικούς πρόσβασης

Τώρα, ας συμπιέσουμε αρχεία με ξεχωριστούς κωδικούς πρόσβασης. Θα χρησιμοποιήσουμε τρία δείγμα αρχεία (`alice29.txt`, `asyoulik.txt` και `fields.c`) με διαφορετικούς κωδικούς πρόσβασης για το καθένα.

```csharp
using (FileStream zipFile = File.Open(dataDir + "CompressFilesWithIndividualPasswords_out.zip", FileMode.Create))
{
    FileInfo source1 = new FileInfo(dataDir + "alice29.txt");
    FileInfo source2 = new FileInfo(dataDir + "asyoulik.txt");
    FileInfo source3 = new FileInfo(dataDir + "fields.c");

    using (var archive = new Archive())
    {
        // Compress each file with an individual password
        archive.CreateEntry("alice29.txt", source1, true, new ArchiveEntrySettings(new DeflateCompressionSettings(), new TraditionalEncryptionSettings("pass1")));
        archive.CreateEntry("asyoulik.txt", source2, true, new ArchiveEntrySettings(new DeflateCompressionSettings(), new AesEcryptionSettings("pass2", EncryptionMethod.AES128)));
        archive.CreateEntry("fields.c", source3, true, new ArchiveEntrySettings(new DeflateCompressionSettings(), new AesEcryptionSettings("pass3", EncryptionMethod.AES256)));
        
        // Save the compressed files
        archive.Save(zipFile);
    }
}
```

## Πώς να κρυπτογραφήσετε αρχεία zip με κωδικούς πρόσβασης ανά αρχείο;

Αναθέστε έναν μοναδικό κωδικό πρόσβασης σε κάθε αρχείο όταν το προσθέτετε στο αρχείο, και το Aspose.Zip θα εφαρμόσει αυτόματα κρυπτογράφηση AES‑256 σε κάθε καταχώρηση. Αυτή η προσέγγιση σας επιτρέπει να διαχειρίζεστε την πρόσβαση ανά αρχείο, κάτι που είναι χρήσιμο σε σενάρια όπου διαφορετικοί παραλήπτες χρειάζονται διαφορετικά διαπιστευτήρια.

## Πώς να κρυπτογραφήσετε zip χρησιμοποιώντας AES‑256;

`EncryptionAlgorithm.Aes256` καθορίζει τον αλγόριθμο κρυπτογράφησης AES‑256 για τις καταχωρήσεις ZIP. Χρησιμοποιήστε τη ρύθμιση `EncryptionAlgorithm.Aes256` σε κάθε `ZipEntry` για να ενεργοποιήσετε την κρυπτογράφηση zip AES‑256. Ο αλγόριθμος παρέχει δύναμη κλειδιού 256‑bit, διασφαλίζοντας ότι ακόμη και ισχυροί επιτιθέμενοι δεν μπορούν να πραγματοποιήσουν brute‑force στο αρχείο χωρίς τον σωστό κωδικό πρόσβασης.
