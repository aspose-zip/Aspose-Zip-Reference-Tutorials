# Δημιουργία Αρχειοθήκης ZIP με Προστασία Κωδικού με Aspose.Zip για .NET

Στον χώρο της ανάπτυξης .NET, η εκμάθηση του πώς να **δημιουργήσετε αρχεία zip με προστασία κωδικού** είναι ένα κρίσιμο στοιχείο του σχεδιασμού εφαρμογών. Το Aspose.Zip για .NET προσφέρει μια ισχυρή λύση για **προσθήκη κωδικού σε zip** αρχεία χρησιμοποιώντας παραδοσιακή κρυπτογράφηση κωδικού. Αυτός ο οδηγός βήμα‑βήμα θα σας καθοδηγήσει στη διαδικασία, εξασφαλίζοντας ότι τα αρχειοθετημένα δεδομένα σας παραμένουν εμπιστευτικά και ασφαλή.

## Γρήγορες Απαντήσεις
- **Τι σημαίνει “create password protected zip”;** Σημαίνει τη δημιουργία ενός αρχείου ZIP του οποίου τα περιεχόμενα κρυπτογραφούνται και μπορούν να ανοιχτούν μόνο με τον σωστό κωδικό.  
- **Ποια βιβλιοθήκη μπορώ να χρησιμοποιήσω;** Το Aspose.Zip για .NET παρέχει ενσωματωμένη υποστήριξη για παραδοσιακή προστασία κωδικού.  
- **Χρειάζομαι άδεια;** Διατίθεται δωρεάν δοκιμαστική έκδοση, αλλά απαιτείται εμπορική άδεια για χρήση σε παραγωγή.  
- **Μπορώ να το χρησιμοποιήσω με .NET Core;** Ναι, η βιβλιοθήκη λειτουργεί με .NET Framework, .NET Core και .NET 5/6+.  
- **Πόσο χρόνο διαρκεί η υλοποίηση;** Συνήθως λιγότερο από 10 λεπτά για ένα βασικό αρχείο zip με προστασία κωδικού.

## Τι είναι το “create password protected zip”;
Η δημιουργία ενός zip με προστασία κωδικού σημαίνει τη συμπίεση ενός ή περισσότερων αρχείων σε ένα κοντέινερ ZIP και την κρυπτογράφηση του κοντέινερ με έναν κωδικό. Το προκύπτον αρχείο μπορεί να μοιραστεί ή να αποθηκευτεί με ασφάλεια, επειδή τα περιεχόμενά του είναι μη αναγνώσιμα χωρίς τον σωστό κωδικό.

## Γιατί να χρησιμοποιήσετε το Aspose.Zip για προστασία κωδικού αρχείων ZIP;
Η παραδοσιακή κρυπτογράφηση ZIP υποστηρίζεται από το 99 % των επιτραπέζιων και κινητών εργαλείων αρχειοθέτησης, καθιστώντας την αξιόπιστη επιλογή για διανομή μεταξύ πλατφορμών. Το Aspose.Zip διαχειρίζεται **πάνω από 50 μορφές συμπίεσης**, επεξεργάζεται αρχεία έως 5 GB χωρίς να φορτώνει ολόκληρο το αρχείο στη μνήμη, και προσθέτει τον κωδικό με μία μόνο κλήση API, εξαλείφοντας την ανάγκη για εξωτερικά εργαλεία.

## Εισαγωγή Χώρων Ονομάτων
Πρώτα, εισάγετε τους χώρους ονομάτων που σας δίνουν πρόσβαση στις κλάσεις συμπίεσης και κρυπτογράφησης.

```csharp
using Aspose.Zip;
using System.IO;
using Aspose.Zip.Saving;
```

## Βήμα 1: Άνοιγμα του Καταλόγου Πόρων
Εντοπίστε τον κατάλογο που περιέχει τα αρχεία που θέλετε να αρχειοθετήσετε. Αυτή η διαδρομή θα χρησιμοποιηθεί κατά τη δημιουργία του ροής ZIP.

## Βήμα 2: Δημιουργία Αρχείου με Παραδοσιακό Κωδικό
Τώρα θα δημιουργήσουμε το αρχείο και θα **προσθέσουμε κωδικό σε zip** χρησιμοποιώντας το `TraditionalEncryptionSettings`. Ο κωδικός `"p@s$"` είναι μόνο ένα παράδειγμα· αντικαταστήστε τον με ένα ισχυρό μυστικό της επιλογής σας.

`TraditionalEncryptionSettings` ορίζει τις παραδοσιακές παραμέτρους κρυπτογράφησης ZIP, όπως ο κωδικός και η ισχύς κρυπτογράφησης.  

```csharp
//ExStart: PasswordProtectArchiveWithTraditionalPassword
using (FileStream zipFile = File.Open(dataDir + "CompressWithTraditionalEncryption_out.zip", FileMode.Create))
{
    using (FileStream source1 = File.Open(dataDir + "alice29.txt", FileMode.Open, FileAccess.Read))
    {
        var archive = new Archive(new ArchiveEntrySettings(null, new TraditionalEncryptionSettings("p@s$")));
        archive.CreateEntry("alice29.txt", source1);
        archive.Save(zipFile);
    }
}
//ExEnd: PasswordProtectArchiveWithTraditionalPassword 
```

> **Συμβουλή:** Αποθηκεύστε τον κωδικό με ασφάλεια (π.χ., στο Azure Key Vault) αντί να τον κωδικοποιήσετε σκληρά.

## Βήμα 3: Αποθήκευση του Αρχείου
Η κλήση `archive.Save(zipFile);` γράφει την ενέργεια **αποθήκευσης zip με κωδικό** στο δίσκο. Μετά από αυτό το βήμα, το αρχείο `CompressWithTraditionalEncryption_out.zip` είναι ένα πλήρως προστατευμένο με κωδικό αρχείο ZIP έτοιμο για διανομή.

## Πώς να συμπιέσετε αρχεία με κωδικό σε μία γραμμή;
Μπορείτε να συμπιέσετε και να προστατέψετε έναν φάκελο σε μία δήλωση συνδέοντας το `Archive.Create()` με το `TraditionalEncryptionSettings`. Το `Archive.Create()` αρχικοποιεί μια νέα παρουσία αρχείου ZIP, και οι ρυθμίσεις εφαρμόζουν τον κωδικό. Αυτή η εντολή‑μιας‑γραμμής δημιουργεί το αρχείο, εφαρμόζει τον κωδικό και γράφει το αρχείο στο δίσκο, εξοικονομώντας χρόνο και κώδικα boilerplate.
