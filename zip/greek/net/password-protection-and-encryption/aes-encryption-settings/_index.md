Όλες οι λειτουργίες εκτελούνται σε ροή, έτσι ακόμη και αρχεία πολλαπλών gigabyte επεξεργάζονται με ελάχιστη χρήση μνήμης.

## Βήμα 2: αρχικοποιήστε το αρχείο με ρυθμίσεις κρυπτογράφησης AES

Η κλάση `SevenZipAESEncryptionSettings` αποθηκεύει τον κωδικό και ρυθμίζει την κρυπτογράφηση AES‑256 για το αρχείο.  
Η κλάση `SevenZipEntrySettings` ρυθμίζει τις επιλογές κάθε καταχώρησης, όπως κρυπτογράφηση και συμπίεση.  

```csharp
//ExStart: AESEncryptionSettings
using (var archive = new SevenZipArchive(new SevenZipEntrySettings(null, new SevenZipAESEncryptionSettings("p@s$"))))
{
    archive.CreateEntry("data.bin", new MemoryStream(new byte[] { 0x00, 0xFF }));
    archive.Save("archive.7z");
}
//ExEnd: AESEncryptionSettings
```

## Συνηθισμένα προβλήματα και πώς να τα αποφύγετε

- **Πολυπλοκότητα κωδικού:** Χρησιμοποιήστε τουλάχιστον 12 χαρακτήρες, συνδυάζοντας κεφαλαία, πεζά, αριθμούς και σύμβολα. Οι αδύναμοι κωδικοί μπορούν να σπάσουν σε λίγα λεπτά.  
- **Όρια μεγέθους αρχείου:** Ενώ το Aspose.Zip μεταδίδει δεδομένα σε ροή, αρχεία μεγαλύτερα από **4 GB** ενεργοποιούν αυτόματα την επέκταση ZIP64, την οποία η βιβλιοθήκη ενεργοποιεί χωρίς επιπλέον κώδικα.  
- **Λανθασμένη επιλογή αλγορίθμου:** `EncryptionAlgorithm.Aes256` καθορίζει τον αλγόριθμο κρυπτογράφησης AES‑256 για το αρχείο. Επαληθεύστε ότι το `EncryptionAlgorithm.Aes256` είναι ορισμένο πριν καλέσετε το `Save`; διαφορετικά το αρχείο θα δημιουργηθεί χωρίς προστασία.
