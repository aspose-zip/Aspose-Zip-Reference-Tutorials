# Aspose.Zip का उपयोग करके .NET में पासवर्ड के साथ ज़िप बनाएं

## परिचय

इस ट्यूटोरियल में आप Aspose.Zip का उपयोग करके .NET एप्लिकेशन में **create zip with password** कैसे बनाते हैं, सीखेंगे। सुरक्षित संपीड़न आवश्यक है जब आपको गोपनीय डेटा प्रेषित करना हो या संवेदनशील दस्तावेज़ों को अनधिकृत पहुंच से बचाते हुए संग्रहीत करना हो। लाइब्रेरी की अंतर्निहित AES‑256 ज़िप एन्क्रिप्शन आपको प्रत्येक एंट्री को व्यक्तिगत रूप से सुरक्षित करने देती है, जिससे आप GDPR और HIPAA जैसे अनुपालन मानकों को पूरा कर सकते हैं।

## त्वरित उत्तर

- **Aspose.Zip क्या करता है?** यह ZIP आर्काइव बनाता और संशोधित करता है, जिसमें प्रति‑फ़ाइल पासवर्ड सुरक्षा शामिल है।  
- **मैं कितने पासवर्ड असाइन कर सकता हूँ?** प्रति फ़ाइल एक अलग पासवर्ड; अनलिमिटेड एंट्रीज़।  
- **कौन सा एन्क्रिप्शन एल्गोरिद्म उपयोग किया जाता है?** AES‑256, 256‑बिट सुरक्षा प्रदान करता है।  
- **परीक्षण के लिए मुझे लाइसेंस चाहिए?** एक मुफ्त ट्रायल उपलब्ध है; उत्पादन के लिए लाइसेंस आवश्यक है।  
- **कौन से .NET संस्करण समर्थित हैं?** .NET Framework 4.5+, .NET Core 3.1+, .NET 5/6/7.

## create zip with password क्या है?

वाक्यांश “create zip with password” का अर्थ है एक ZIP आर्काइव बनाना जहाँ प्रत्येक एंट्री को उपयोगकर्ता‑परिभाषित पासवर्ड से एन्क्रिप्ट किया जाता है। Aspose.Zip इसे इस प्रकार लागू करता है कि आप आर्काइव में जोड़ने वाली प्रत्येक फ़ाइल को पासवर्ड असाइन कर सकते हैं, जिससे प्रत्येक फ़ाइल व्यक्तिगत रूप से सुरक्षित रहती है।

## ZIP आर्काइव्स के लिए पासवर्ड सुरक्षा क्यों उपयोग करें?

पासवर्ड सुरक्षा एक मजबूत सुरक्षा परत जोड़ती है जबकि आर्काइव का आकार छोटा रखती है। Aspose.Zip **30+ compression algorithms** का समर्थन करता है और **AES‑256 zip encryption** प्रदान करता है, जो **256‑bit security** तक देता है। यह **multi‑hundred‑megabyte archives** को पूरी फ़ाइल को मेमोरी में लोड किए बिना प्रोसेस कर सकता है, सामान्य सर्वर हार्डवेयर पर **500 MB/s throughput** तक प्राप्त करता है। यह प्रदर्शन उच्च‑वॉल्यूम बैच जॉब्स और रियल‑टाइम फ़ाइल ट्रांसफ़र के लिए आदर्श बनाता है।

## .NET में पासवर्ड के साथ ज़िप कैसे बनाएं?

लक्षित फ़ोल्डर लोड करें, एक `ZipFile` ऑब्जेक्ट बनाएं, प्रत्येक फ़ाइल को उसके स्वयं के पासवर्ड के साथ जोड़ें, और अंत में `Save` को कॉल करके आर्काइव लिखें। यह पूरी प्रक्रिया केवल कुछ कोड लाइनों की आवश्यकता रखती है और यह सुनिश्चित करती है कि प्रत्येक एंट्री आपके द्वारा निर्दिष्ट पासवर्ड से एन्क्रिप्ट हो।

### चरण 1: रिसोर्स डायरेक्टरी पाथ सेट करें

अपनी फ़ाइलों के स्थित रिसोर्स डायरेक्टरी का पाथ निर्धारित करें।

```csharp
string dataDir = "Your Document Directory";
```

### चरण 2: व्यक्तिगत पासवर्ड के साथ फ़ाइलें संपीड़ित करें

अब, चलिए व्यक्तिगत पासवर्ड के साथ फ़ाइलें संपीड़ित करते हैं। हम तीन नमूना फ़ाइलों (`alice29.txt`, `asyoulik.txt`, और `fields.c`) का उपयोग करेंगे, प्रत्येक के लिए अलग-अलग पासवर्ड के साथ।

```csharp
using (FileStream zipFile = File.Open(dataDir + "CompressFilesWithIndividualPasswords_out.zip", FileMode.Create))
{
    FileInfo source1 = new FileInfo(dataDir + "alice29.txt");
    FileInfo source2 = new FileInfo(dataDir + "asyoulik.txt");
    FileInfo source3 = new FileInfo(dataDir + "fields.c");

    using (var archive = new Archive())
    {
        // Compress each file with an individual password
        archive.CreateEntry("alice29.txt", source1, true, new ArchiveEntrySettings(new DeflateCompressionSettings(), new TraditionalEncryptionSettings("pass1")));
        archive.CreateEntry("asyoulik.txt", source2, true, new ArchiveEntrySettings(new DeflateCompressionSettings(), new AesEcryptionSettings("pass2", EncryptionMethod.AES128)));
        archive.CreateEntry("fields.c", source3, true, new ArchiveEntrySettings(new DeflateCompressionSettings(), new AesEcryptionSettings("pass3", EncryptionMethod.AES256)));
        
        // Save the compressed files
        archive.Save(zipFile);
    }
}
```

## प्रति‑फ़ाइल पासवर्ड के साथ ज़िप फ़ाइलें कैसे एन्क्रिप्ट करें?

जब आप फ़ाइल को आर्काइव में जोड़ते हैं, तो प्रत्येक फ़ाइल को एक अनूठा पासवर्ड असाइन करें, और Aspose.Zip स्वचालित रूप से प्रत्येक एंट्री पर AES‑256 एन्क्रिप्शन लागू करेगा। यह तरीका आपको प्रति‑फ़ाइल आधार पर एक्सेस प्रबंधित करने देता है, जो उन स्थितियों में उपयोगी है जहाँ विभिन्न प्राप्तकर्ताओं को विभिन्न क्रेडेंशियल्स चाहिए।

## AES‑256 का उपयोग करके ज़िप कैसे एन्क्रिप्ट करें?

`EncryptionAlgorithm.Aes256` ZIP एंट्रीज़ के लिए AES‑256 एन्क्रिप्शन एल्गोरिद्म निर्दिष्ट करता है। प्रत्येक `ZipEntry` पर `EncryptionAlgorithm.Aes256` सेटिंग का उपयोग करके AES‑256 ज़िप एन्क्रिप्शन सक्षम करें। यह एल्गोरिद्म 256‑बिट कुंजी शक्ति प्रदान करता है, जिससे यहाँ तक कि शक्तिशाली हमलावर भी सही पासवर्ड के बिना आर्काइव को ब्रूट‑फ़ोर्स नहीं कर सकते।
