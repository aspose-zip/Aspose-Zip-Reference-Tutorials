## Jak vytvořit zip soubor bez komprese v .NET?

`ZipArchive` je třída, která představuje zip kontejner a poskytuje metody pro vytváření, čtení a úpravu zip souborů.  
`CompressionMethod` určuje, jak je položka uložena; volba `Store` ukládá data bez komprese.  

Načtěte své soubory do instance `ZipArchive`, nastavte pro každou položku `CompressionMethod` na `Store` a poté archiv uložte – to je kompletní workflow “zip soubor bez komprese” ve třech stručných krocích. Tento přístup zachová původní velikost souboru beze změny a zároveň vám poskytne jeden přenosný kontejner, který lze efektivně přenášet nebo ukládat.

## Proč použít Aspose.Zip k vytváření zip archivů v .NET?

Aspose.Zip zpracovává archivy až do **10 GB** bez načítání celého souboru do paměti a podporuje **více než 30 metod komprese** (včetně Store, Deflate, Bzip2, LZMA, PPMd a Enhanced Deflate). Knihovna poskytuje **až 2× rychlejší** archivaci ve srovnání s nativním .NET `System.IO.Compression` při práci s velkými dávkami, a zároveň nabízí vestavěné šifrování a podporu Unicode názvů souborů.

## Často kladené otázky

**Q: Mohu použít Aspose.Zip k vytvoření zip archivu .net na .NET Core?**  
A: Rozhodně. Aspose.Zip plně podporuje .NET Core 2.0–3.1 a .NET 5–10.

**Q: Jak upravím existující archiv, aniž bych ho nejprve rozbalil?**  
A: Použijte API “modify zip file c#” – můžete přímo do proudu archivu přidávat, mazat nebo přejmenovávat položky.

**Q: Která metoda komprese poskytuje nejlepší poměr pro textové soubory?**  
A: Obecně Bzip2 nebo LZMA poskytují vyšší kompresi pro text, ale jsou pomalejší než Deflate. Otestujte obě, abyste našli správnou rovnováhu.

**Q: Existuje způsob, jak šifrovat soubory při vytváření zip archivu?**  
A: Ano, Aspose.Zip podporuje AES šifrování. Můžete nastavit heslo na objekt ZipArchive před uložením.

**Q: Musím se starat o kódování názvů souborů?**  
A: Aspose.Zip automaticky zpracovává Unicode názvy souborů, ale můžete explicitně nastavit kódování, pokud potřebujete kompatibilitu se staršími systémy.

**Q: Mohu přidat soubory do existujícího zipu bez jeho přetvoření?**  
A: Ano, API poskytuje metodu **add files zip .net**, která vám umožní přímo připojit nové položky.

**Q: Podporuje Aspose.Zip streamování velkých souborů?**  
A: Ano. Můžete pracovat se streamy, abyste se vyhnuli načítání celých souborů do paměti, což je ideální pro scénáře ve velkém měřítku.
