## كيف يمكنني استخراج ملف واحد من أرشيف ZIP في C#؟

قم بتحميل الأرشيف، أرفق معالج تقدم، واستدعِ `Extract` على الإدخال المطلوب – هذا كل ما تحتاجه لاستخراج ملف واحد مع مراقبة التقدم. النمط التالي يستخرج الإدخال الأول، يطبع النسبة المئوية إلى وحدة التحكم، ويكتب الملف إلى القرص في بضع أسطر من الشيفرة فقط.

كائن `Archive` يمثل ملف ZIP في الذاكرة. عندما تستدعي `archive.Extract(entry, destinationPath)`، تقوم Aspose.Zip ببث البيانات وتطلق حدث `Progress` بعد كل جزء، مما يتيح لك عرض التقدم في الوقت الفعلي.

### الخطوة 1: تحديد دليل المستندات الخاص بك

ابدأ بتحديد الدليل الذي تُخزن فيه مستنداتك. استبدل `"Your Document Directory"` بالمسار الفعلي.

```csharp
string dataDir = Path.Combine(Environment.CurrentDirectory, "Your Document Directory");
Directory.CreateDirectory(dataDir);
```

### الخطوة 2: إنشاء ملف مضغوط (إعداد تجريبي)

النداء التالي ينشئ ملف ZIP تجريبي سنقوم بفك ضغطه لاحقًا. هذا يعكس سيناريو شائع حيث لديك بالفعل أرشيف ZIP.

```csharp
string zipPath = Path.Combine(dataDir, "sample.zip");
using (var archive = new Archive())
{
    archive.AddFile(Path.Combine(dataDir, "sample.txt"));
    archive.Save(zipPath);
}
```

### الخطوة 3: فك ضغط الملف – استخراج ملف zip واحد

الآن، دعنا نتعمق في صلب الموضوع – استخراج الإدخال الواحد مع **monitoring zip progress c#**. الشيفرة أدناه تفتح أرشيف ZIP، تُرفق معالج تقدم، وتستخرج الإدخال الأول إلى ملف نصي.

```csharp
using (var archive = new Archive(zipPath))
{
    // Attach progress handler
    archive.Progress += (sender, args) =>
    {
        Console.WriteLine($"{args.ProgressPercentage}% decompressed");
    };

    // Extract the first entry (index 0)
    var entry = archive.Entries[0];
    string outputPath = Path.Combine(dataDir, entry.FileName);
    entry.Extract(outputPath);
}
```

هذا المقتطف **extracts a single zip entry** بينما يطبع التقدم في الوقت الفعلي (مثال: “30% decompressed”). يمكنك تعديل الفهرس (`Entries[0]`) لاستهداف أي ملف آخر داخل الأرشيف.

## استخراج إدخال zip .net – نصائح وأفضل الممارسات

- **معالجة المسار** – استخدم `Path.Combine(dataDir, "file.zip")` لتجنب مشاكل الفواصل الخاصة بالمنصة.  
- **zip محمي بكلمة مرور c#** – عيّن `archive.Password = "yourPassword"` قبل استدعاء `Extract`.  
- **إدخالات متعددة** – كرّر عبر `archive.Entries` وتطابق باستخدام `FileName` عندما تحتاج إلى استخراج أكثر من ملف.  
- **ضغط ملفات متعددة zip** – يمكنك لاحقًا استدعاء `archive.AddFile(path)` لتجميع عدة ملفات في أرشيف جديد.

- **فواصل مسار الملف** – استخدم `Path.Combine` لضمان الأمان عبر المنصات.

- **إدخالات متعددة** – كرّر عبر `archive.Entries` وتطابق باستخدام `FileName`.  
- **ضغط ملفات متعددة zip** – إذا احتجت لاحقًا لتجميع عدة ملفات، تسمح لك طريقة `AddFile` في Aspose.Zip بإنشاء أرشيفات دون مغادرة الـ API.
