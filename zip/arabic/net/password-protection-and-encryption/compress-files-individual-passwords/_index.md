# إنشاء zip محمي بكلمة مرور في .NET باستخدام Aspose.Zip

## المقدمة

في هذا الدرس ستتعلم كيفية **إنشاء zip محمي بكلمة مرور** في تطبيق .NET باستخدام Aspose.Zip. الضغط الآمن ضروري عندما تحتاج إلى نقل بيانات سرية أو تخزين مستندات حساسة دون تعريضها للوصول غير المصرح به. تشفير zip المدمج في المكتبة باستخدام AES‑256 يسمح لك بحماية كل مدخل على حدة، مما يساعدك على تلبية معايير الامتثال مثل GDPR وHIPAA.

## إجابات سريعة
- **ماذا يفعل Aspose.Zip؟** يقوم بإنشاء ومعالجة أرشيفات ZIP، بما في ذلك حماية كلمة المرور لكل ملف.  
- **كم عدد كلمات المرور التي يمكنني تعيينها؟** كلمة مرور مميزة لكل ملف؛ عدد غير محدود من الإدخالات.  
- **ما هو خوارزمية التشفير المستخدمة؟** AES‑256، توفر أمانًا بمفتاح 256‑بت.  
- **هل أحتاج إلى ترخيص للاختبار؟** نسخة تجريبية مجانية متاحة؛ يلزم الترخيص للإنتاج.  
- **ما إصدارات .NET المدعومة؟** .NET Framework 4.5+، .NET Core 3.1+، .NET 5/6/7.

## ما هو إنشاء zip محمي بكلمة مرور؟
تشير عبارة “إنشاء zip محمي بكلمة مرور” إلى توليد أرشيف ZIP حيث يتم تشفير كل مدخل بكلمة مرور يحددها المستخدم. يطبق Aspose.Zip ذلك من خلال السماح لك بتعيين كلمة مرور لكل ملف تضيفه إلى الأرشيف، مما يضمن حماية كل ملف على حدة.

## لماذا نستخدم حماية كلمة المرور لأرشيفات ZIP؟
تضيف حماية كلمة المرور طبقة أمان قوية مع الحفاظ على حجم الأرشيف صغيرًا. يدعم Aspose.Zip **أكثر من 30 خوارزمية ضغط** ويقدم **تشفير zip AES‑256**، مما يوفر **أمانًا بمفتاح 256‑بت**. يمكنه معالجة **أرشيفات بمئات الميغابايت** دون تحميل الملف بالكامل في الذاكرة، محققًا **سرعة نقل تصل إلى 500 MB/s** على أجهزة الخادم النموذجية. هذا الأداء يجعله مثاليًا للوظائف الدفعية ذات الحجم الكبير ونقل الملفات في الوقت الفعلي.

## كيفية إنشاء zip محمي بكلمة مرور في .NET؟

حمّل المجلد الهدف، أنشئ كائن `ZipFile`، أضف كل ملف مع كلمة مروره الخاصة، وأخيرًا استدعِ `Save` لكتابة الأرشيف. هذه العملية بالكامل تتطلب بضع أسطر من الشيفرة وتضمن تشفير كل مدخل بكلمة المرور التي تحددها.

### الخطوة 1: تحديد مسار دليل الموارد

حدد المسار إلى دليل الموارد حيث توجد ملفاتك.

```csharp
string dataDir = "Your Document Directory";
```

### الخطوة 2: ضغط الملفات بكلمات مرور فردية

الآن، لنضغط الملفات بكلمات مرور فردية. سنستخدم ثلاثة ملفات نموذجية (`alice29.txt`, `asyoulik.txt`, و `fields.c`) مع كلمات مرور مميزة لكل منها.

```csharp
using (FileStream zipFile = File.Open(dataDir + "CompressFilesWithIndividualPasswords_out.zip", FileMode.Create))
{
    FileInfo source1 = new FileInfo(dataDir + "alice29.txt");
    FileInfo source2 = new FileInfo(dataDir + "asyoulik.txt");
    FileInfo source3 = new FileInfo(dataDir + "fields.c");

    using (var archive = new Archive())
    {
        // Compress each file with an individual password
        archive.CreateEntry("alice29.txt", source1, true, new ArchiveEntrySettings(new DeflateCompressionSettings(), new TraditionalEncryptionSettings("pass1")));
        archive.CreateEntry("asyoulik.txt", source2, true, new ArchiveEntrySettings(new DeflateCompressionSettings(), new AesEcryptionSettings("pass2", EncryptionMethod.AES128)));
        archive.CreateEntry("fields.c", source3, true, new ArchiveEntrySettings(new DeflateCompressionSettings(), new AesEcryptionSettings("pass3", EncryptionMethod.AES256)));
        
        // Save the compressed files
        archive.Save(zipFile);
    }
}
```

## كيفية تشفير ملفات zip بكلمات مرور لكل ملف؟

قم بتعيين كلمة مرور فريدة لكل ملف عند إضافته إلى الأرشيف، وسيقوم Aspose.Zip تلقائيًا بتطبيق تشفير AES‑256 على كل مدخل. يتيح لك هذا النهج إدارة الوصول على أساس كل ملف، وهو مفيد في السيناريوهات التي يحتاج فيها المستلمون المختلفون إلى بيانات اعتماد مختلفة.

## كيفية تشفير zip باستخدام AES‑256؟

`EncryptionAlgorithm.Aes256` يحدد خوارزمية التشفير AES‑256 لمدخلات ZIP. استخدم إعداد `EncryptionAlgorithm.Aes256` على كل `ZipEntry` لتمكين تشفير zip AES‑256. توفر الخوارزمية قوة مفتاح 256‑بت، مما يضمن أن حتى المهاجمين القويين لا يمكنهم اختراق الأرشيف دون كلمة المرور الصحيحة.

## حالات الاستخدام الشائعة لكلمة مرور zip لكل ملف

- **الامتثال التنظيمي** – احمِ سجلات المرضى أو البيانات المالية بكلمات مرور فردية قبل إرسالها إلى المدققين.  
- **منصات SaaS متعددة المستأجرين** – أنشئ أرشيفًا واحدًا يحتوي على بيانات كل مستأجر، مؤمنًا بكلمة مرور خاصة بالمستأجر.
