# สร้าง zip พร้อมรหัสผ่านใน .NET ด้วย Aspose.Zip

## บทนำ

ในบทเรียนนี้คุณจะได้เรียนรู้วิธี **สร้าง zip พร้อมรหัสผ่าน** ในแอปพลิเคชัน .NET ด้วย Aspose.Zip การบีบอัดที่ปลอดภัยเป็นสิ่งสำคัญเมื่อคุณต้องส่งข้อมูลที่เป็นความลับหรือจัดเก็บเอกสารที่ละเอียดอ่อนโดยไม่ให้ผู้ที่ไม่ได้รับอนุญาตเข้าถึง ไลบรารีนี้มีการเข้ารหัส zip AES‑256 ในตัวที่ช่วยให้คุณปกป้องแต่ละรายการแยกกัน ทำให้คุณสามารถปฏิบัติตามมาตรฐานความเป็นส่วนตัวเช่น GDPR และ HIPAA ได้

## คำตอบอย่างรวดเร็ว
- **Aspose.Zip ทำอะไร?** มันสร้างและจัดการไฟล์ ZIP รวมถึงการป้องกันด้วยรหัสผ่านต่อไฟล์ด้วย.  
- **ฉันสามารถกำหนดรหัสผ่านได้กี่รหัส?** หนึ่งรหัสผ่านที่แตกต่างต่อไฟล์; จำนวนรายการไม่จำกัด.  
- **อัลกอริทึมการเข้ารหัสที่ใช้คืออะไร?** AES‑256 ให้ความปลอดภัยระดับ 256‑บิต.  
- **ฉันต้องมีลิขสิทธิ์สำหรับการทดสอบหรือไม่?** มีรุ่นทดลองฟรี; จำเป็นต้องมีลิขสิทธิ์สำหรับการใช้งานจริง.  
- **เวอร์ชัน .NET ที่รองรับคืออะไร?** .NET Framework 4.5+, .NET Core 3.1+, .NET 5/6/7.

## การสร้าง zip พร้อมรหัสผ่านคืออะไร?
วลี “สร้าง zip พร้อมรหัสผ่าน” หมายถึงการสร้างไฟล์ ZIP ที่แต่ละรายการถูกเข้ารหัสด้วยรหัสผ่านที่ผู้ใช้กำหนด Aspose.Zip ทำให้คุณสามารถกำหนดรหัสผ่านให้กับไฟล์แต่ละไฟล์ที่เพิ่มเข้าไปในไฟล์เก็บข้อมูล ทำให้แต่ละไฟล์ได้รับการปกป้องแยกกัน

## ทำไมต้องใช้การป้องกันด้วยรหัสผ่านสำหรับไฟล์ ZIP?
การป้องกันด้วยรหัสผ่านเพิ่มชั้นความปลอดภัยที่แข็งแกร่งในขณะที่ขนาดไฟล์เก็บข้อมูลยังคงเล็ก Aspose.Zip รองรับ **อัลกอริทึมการบีบอัดกว่า 30 รายการ** และให้ **การเข้ารหัส zip AES‑256** ส่งมอบความปลอดภัยระดับ **256‑บิต** สามารถประมวลผล **ไฟล์เก็บข้อมูลหลายร้อยเมกะไบต์** โดยไม่ต้องโหลดไฟล์ทั้งหมดเข้าสู่หน่วยความจำ ทำให้ได้อัตราการถ่ายโอนสูงสุด **500 MB/s** บนฮาร์ดแวร์เซิร์ฟเวอร์ทั่วไป ประสิทธิภาพนี้ทำให้เหมาะกับงานแบตช์ปริมาณสูงและการถ่ายโอนไฟล์แบบเรียลไทม์

## นำเข้าเนมสเปซ

ในโครงการ .NET ของคุณ ตรวจสอบให้แน่ใจว่าได้นำเข้าเนมสเปซที่จำเป็น:

`ZipFile` คือคลาสหลักของ Aspose.Zip สำหรับสร้างไฟล์ ZIP และกำหนดรหัสผ่านแยกให้แต่ละรายการ.

```csharp
using Aspose.Zip;
using Aspose.Zip.Saving;
using System.IO;
```

## วิธีสร้าง zip พร้อมรหัสผ่านใน .NET?

โหลดโฟลเดอร์เป้าหมาย, สร้างอ็อบเจ็กต์ `ZipFile`, เพิ่มไฟล์แต่ละไฟล์พร้อมรหัสผ่านของมันเอง, แล้วเรียก `Save` เพื่อบันทึกไฟล์เก็บข้อมูล กระบวนการทั้งหมดนี้ใช้เพียงไม่กี่บรรทัดของโค้ดและรับประกันว่าทุกรายการจะถูกเข้ารหัสด้วยรหัสผ่านที่คุณระบุ

### ขั้นตอนที่ 1: ตั้งค่าพาธของโฟลเดอร์ทรัพยากร

กำหนดพาธไปยังโฟลเดอร์ทรัพยากรที่ไฟล์ของคุณอยู่

```csharp
string dataDir = "Your Document Directory";
```

### ขั้นตอนที่ 2: บีบอัดไฟล์ด้วยรหัสผ่านแยกกัน

ตอนนี้เราจะบีบอัดไฟล์ด้วยรหัสผ่านแยกกัน เราจะใช้ไฟล์ตัวอย่างสามไฟล์ (`alice29.txt`, `asyoulik.txt`, และ `fields.c`) โดยกำหนดรหัสผ่านที่แตกต่างสำหรับแต่ละไฟล์

```csharp
using (FileStream zipFile = File.Open(dataDir + "CompressFilesWithIndividualPasswords_out.zip", FileMode.Create))
{
    FileInfo source1 = new FileInfo(dataDir + "alice29.txt");
    FileInfo source2 = new FileInfo(dataDir + "asyoulik.txt");
    FileInfo source3 = new FileInfo(dataDir + "fields.c");

    using (var archive = new Archive())
    {
        // Compress each file with an individual password
        archive.CreateEntry("alice29.txt", source1, true, new ArchiveEntrySettings(new DeflateCompressionSettings(), new TraditionalEncryptionSettings("pass1")));
        archive.CreateEntry("asyoulik.txt", source2, true, new ArchiveEntrySettings(new DeflateCompressionSettings(), new AesEcryptionSettings("pass2", EncryptionMethod.AES128)));
        archive.CreateEntry("fields.c", source3, true, new ArchiveEntrySettings(new DeflateCompressionSettings(), new AesEcryptionSettings("pass3", EncryptionMethod.AES256)));
        
        // Save the compressed files
        archive.Save(zipFile);
    }
}
```

## วิธีเข้ารหัสไฟล์ zip ด้วยรหัสผ่านต่อไฟล์?

กำหนดรหัสผ่านที่ไม่ซ้ำกันให้กับทุกไฟล์เมื่อคุณเพิ่มเข้าไปในไฟล์เก็บข้อมูล และ Aspose.Zip จะทำการเข้ารหัส AES‑256 ให้แต่ละรายการโดยอัตโนมัติ วิธีนี้ช่วยให้คุณจัดการการเข้าถึงตามไฟล์ ซึ่งมีประโยชน์ในสถานการณ์ที่ผู้รับต่างกันต้องการข้อมูลประจำตัวที่แตกต่างกัน

## วิธีเข้ารหัส zip ด้วย AES‑256?

`EncryptionAlgorithm.Aes256` ระบุอัลกอริทึมการเข้ารหัส AES‑256 สำหรับรายการ ZIP ใช้การตั้งค่า `EncryptionAlgorithm.Aes256` บนแต่ละ `ZipEntry` เพื่อเปิดใช้งานการเข้ารหัส zip AES‑256 อัลกอริทึมนี้ให้ความแข็งแกร่งของคีย์ 256‑บิต ทำให้แม้ผู้โจมตีที่มีพลังก็ไม่สามารถทำการ brute‑force ไฟล์เก็บข้อมูลได้หากไม่มีรหัสผ่านที่ถูกต้อง

## กรณีการใช้งานทั่วไปสำหรับรหัสผ่าน zip ต่อไฟล์

- **การปฏิบัติตามกฎระเบียบ** – ปกป้องบันทึกผู้ป่วยหรือรายงานการเงินด้วยรหัสผ่านแยกกันก่อนส่งให้ผู้ตรวจสอบ.
- **แพลตฟอร์ม SaaS แบบหลายผู้เช่า** – สร้างไฟล์เก็บข้อมูลเดียวที่บรรจุข้อมูลของแต่ละผู้เช่า โดยปกป้องด้วยรหัสผ่านเฉพาะผู้เช่า.
- **สคริปต์สำรองข้อมูลอย่างปลอดภัย** – ทำการสำรองข้อมูลอัตโนมัติทุกคืน โดยแต่ละไฟล์ถูกเข้ารหัสด้วยรหัสผ่านที่หมุนเวียนเพื่อเพิ่มความปลอดภัย.
