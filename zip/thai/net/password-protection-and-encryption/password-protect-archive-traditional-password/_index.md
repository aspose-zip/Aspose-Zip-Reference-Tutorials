# สร้างไฟล์ ZIP ที่ป้องกันด้วยรหัสผ่านด้วย Aspose.Zip สำหรับ .NET

ในโลกของการพัฒนา .NET การเรียนรู้วิธี **create password protected zip** archives เป็นส่วนสำคัญของการออกแบบแอปพลิเคชัน Aspose.Zip สำหรับ .NET มีโซลูชันที่แข็งแกร่งเพื่อ **add password to zip** ด้วยการเข้ารหัสรหัสผ่านแบบดั้งเดิม คู่มือขั้นตอนนี้จะพาคุณผ่านกระบวนการ เพื่อให้ข้อมูลที่บีบอัดของคุณยังคงเป็นความลับและปลอดภัย

## คำตอบอย่างรวดเร็ว
- **What does “create password protected zip” mean?** หมายถึงการสร้างไฟล์ ZIP ที่เนื้อหาถูกเข้ารหัสและสามารถเปิดได้เฉพาะด้วยรหัสผ่านที่ถูกต้อง.  
- **Which library can I use?** Aspose.Zip for .NET มีการสนับสนุนในตัวสำหรับการป้องกันด้วยรหัสผ่านแบบดั้งเดิม.  
- **Do I need a license?** มีรุ่นทดลองฟรีให้ใช้ แต่ต้องมีลิขสิทธิ์เชิงพาณิชย์สำหรับการใช้งานในสภาพแวดล้อมจริง.  
- **Can I use this with .NET Core?** ใช่ ไลบรารีทำงานได้กับ .NET Framework, .NET Core, และ .NET 5/6+.  
- **How long does implementation take?** ปกติใช้เวลาน้อยกว่า 10 นาทีสำหรับการสร้างไฟล์ ZIP ที่ป้องกันด้วยรหัสผ่านพื้นฐาน.

## “create password protected zip” คืออะไร?
การสร้างไฟล์ zip ที่ป้องกันด้วยรหัสผ่านหมายถึงการบีบอัดไฟล์หนึ่งหรือหลายไฟล์เข้าไปในคอนเทนเนอร์ ZIP และเข้ารหัสคอนเทนเนอร์ด้วยรหัสผ่าน ไฟล์ที่ได้สามารถแชร์หรือเก็บได้อย่างปลอดภัย เนื่องจากเนื้อหาจะไม่สามารถอ่านได้หากไม่มีรหัสผ่านที่ถูกต้อง.

## ทำไมต้องใช้ Aspose.Zip สำหรับการป้องกันไฟล์ ZIP ด้วยรหัสผ่าน?
การเข้ารหัส ZIP แบบดั้งเดิมได้รับการสนับสนุนจากเครื่องมือบีบอัดไฟล์บนเดสก์ท็อปและมือถือถึง 99 % ทำให้เป็นตัวเลือกที่เชื่อถือได้สำหรับการแจกจ่ายข้ามแพลตฟอร์ม Aspose.Zip รองรับ **50+ compression formats**, ประมวลผลไฟล์บีบอัดขนาดสูงสุดถึง 5 GB โดยไม่ต้องโหลดไฟล์ทั้งหมดเข้าสู่หน่วยความจำ และเพิ่มรหัสผ่านด้วยการเรียก API ครั้งเดียว ทำให้ไม่ต้องใช้เครื่องมือภายนอก.

## นำเข้า Namespaces
ก่อนอื่น ให้นำเข้า namespaces ที่ให้คุณเข้าถึงคลาสการบีบอัดและการเข้ารหัส.

```csharp
using Aspose.Zip;
using System.IO;
using Aspose.Zip.Saving;
```

## ขั้นตอนที่ 1: เปิดไดเรกทอรีทรัพยากร
ระบุไดเรกทอรีที่เก็บไฟล์ที่คุณต้องการบีบอัดเป็นไฟล์เก็บข้อมูล (archive) เส้นทางนี้จะถูกใช้เมื่อสร้างสตรีม ZIP.

## ขั้นตอนที่ 2: สร้าง Archive ด้วยรหัสผ่านแบบดั้งเดิม
ตอนนี้เราจะสร้าง archive และ **add password to zip** โดยใช้ `TraditionalEncryptionSettings` รหัสผ่าน `"p@s$"` เป็นเพียงตัวอย่าง; ให้เปลี่ยนเป็นรหัสลับที่แข็งแรงตามที่คุณต้องการ.

`TraditionalEncryptionSettings` กำหนดพารามิเตอร์การเข้ารหัส ZIP แบบดั้งเดิม เช่น รหัสผ่านและความแข็งแรงของการเข้ารหัส.  

```csharp
//ExStart: PasswordProtectArchiveWithTraditionalPassword
using (FileStream zipFile = File.Open(dataDir + "CompressWithTraditionalEncryption_out.zip", FileMode.Create))
{
    using (FileStream source1 = File.Open(dataDir + "alice29.txt", FileMode.Open, FileAccess.Read))
    {
        var archive = new Archive(new ArchiveEntrySettings(null, new TraditionalEncryptionSettings("p@s$")));
        archive.CreateEntry("alice29.txt", source1);
        archive.Save(zipFile);
    }
}
//ExEnd: PasswordProtectArchiveWithTraditionalPassword 
```

> **Pro tip:** เก็บรหัสผ่านอย่างปลอดภัย (เช่น ใน Azure Key Vault) แทนการเขียนรหัสโดยตรงในโค้ด.

## ขั้นตอนที่ 3: บันทึก Archive
การเรียก `archive.Save(zipFile);` จะบันทึกการทำงาน **save zip with password** ลงดิสก์ หลังจากขั้นตอนนี้ ไฟล์ `CompressWithTraditionalEncryption_out.zip` จะเป็นไฟล์ ZIP ที่ป้องกันด้วยรหัสผ่านอย่างสมบูรณ์พร้อมสำหรับการแจกจ่าย.

## วิธีบีบอัดไฟล์ด้วยรหัสผ่านในบรรทัดเดียว
คุณสามารถบีบอัดและป้องกันโฟลเดอร์ในคำสั่งเดียวโดยเชื่อมต่อ `Archive.Create()` กับ `TraditionalEncryptionSettings` `Archive.Create()` จะสร้างอินสแตนซ์ ZIP archive ใหม่ และการตั้งค่าจะใช้รหัสผ่าน บรรทัดเดียวนี้จะสร้าง archive, ใส่รหัสผ่าน, และบันทึกไฟล์ลงดิสก์ ช่วยประหยัดเวลาและโค้ดที่ซ้ำซ้อน.
