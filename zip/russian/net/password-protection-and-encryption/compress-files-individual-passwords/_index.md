# Создать zip с паролем в .NET с использованием Aspose.Zip

## Введение

В этом руководстве вы узнаете, как **создать zip с паролем** в приложении .NET с использованием Aspose.Zip. Защищённое сжатие необходимо, когда нужно передавать конфиденциальные данные или хранить чувствительные документы, не раскрывая их неавторизованным лицам. Встроенное в библиотеку шифрование zip AES‑256 позволяет защищать каждый элемент отдельно, помогая соответствовать требованиям нормативов, таких как GDPR и HIPAA.

## Быстрые ответы
- **Что делает Aspose.Zip?** Он создаёт и управляет ZIP‑архивами, включая защиту паролем для отдельных файлов.  
- **Сколько паролей я могу назначить?** Один отдельный пароль на файл; количество записей не ограничено.  
- **Какой алгоритм шифрования используется?** AES‑256, обеспечивающий 256‑битную безопасность.  
- **Нужна ли лицензия для тестирования?** Доступна бесплатная пробная версия; для продакшн‑использования требуется лицензия.  
- **Какие версии .NET поддерживаются?** .NET Framework 4.5+, .NET Core 3.1+, .NET 5/6/7.

## Что такое создание zip с паролем?
Фраза «создать zip с паролем» означает генерацию ZIP‑архива, где каждый элемент зашифрован пользовательским паролем. Aspose.Zip реализует это, позволяя назначать пароль каждому файлу, добавляемому в архив, обеспечивая индивидуальную защиту каждого файла.

## Почему использовать защиту паролем для ZIP‑архивов?
Защита паролем добавляет надёжный уровень безопасности, сохраняя небольшой размер архива. Aspose.Zip поддерживает **30+ алгоритмов сжатия** и предлагает **AES‑256 шифрование zip**, обеспечивая до **256‑битной безопасности**. Он может обрабатывать **многосотенные мегабайты архивов** без загрузки всего файла в память, достигая до **500 МБ/с пропускной способности** на типичном серверном оборудовании. Такая производительность делает его идеальным для высокообъёмных пакетных задач и передачи файлов в реальном времени.

## Как создать zip с паролем в .NET?

Загрузите целевую папку, создайте объект `ZipFile`, добавьте каждый файл с собственным паролем и, наконец, вызовите `Save` для записи архива. Весь процесс требует всего несколько строк кода и гарантирует, что каждый элемент зашифрован указанным паролем.

### Шаг 1: установить путь к каталогу ресурсов

Определите путь к каталогу ресурсов, где находятся ваши файлы.

```csharp
string dataDir = "Your Document Directory";
```

### Шаг 2: сжать файлы с индивидуальными паролями

Теперь сожмём файлы с индивидуальными паролями. Мы используем три примерных файла (`alice29.txt`, `asyoulik.txt` и `fields.c`) с разными паролями для каждого.

```csharp
using (FileStream zipFile = File.Open(dataDir + "CompressFilesWithIndividualPasswords_out.zip", FileMode.Create))
{
    FileInfo source1 = new FileInfo(dataDir + "alice29.txt");
    FileInfo source2 = new FileInfo(dataDir + "asyoulik.txt");
    FileInfo source3 = new FileInfo(dataDir + "fields.c");

    using (var archive = new Archive())
    {
        // Compress each file with an individual password
        archive.CreateEntry("alice29.txt", source1, true, new ArchiveEntrySettings(new DeflateCompressionSettings(), new TraditionalEncryptionSettings("pass1")));
        archive.CreateEntry("asyoulik.txt", source2, true, new ArchiveEntrySettings(new DeflateCompressionSettings(), new AesEcryptionSettings("pass2", EncryptionMethod.AES128)));
        archive.CreateEntry("fields.c", source3, true, new ArchiveEntrySettings(new DeflateCompressionSettings(), new AesEcryptionSettings("pass3", EncryptionMethod.AES256)));
        
        // Save the compressed files
        archive.Save(zipFile);
    }
}
```

## Как зашифровать zip‑файлы с паролями для каждого файла?

Назначьте уникальный пароль каждому файлу при добавлении его в архив, и Aspose.Zip автоматически применит шифрование AES‑256 к каждому элементу. Такой подход позволяет управлять доступом на уровне отдельного файла, что полезно в сценариях, когда разным получателям нужны разные учётные данные.

## Как зашифровать zip с использованием AES‑256?

`EncryptionAlgorithm.Aes256` указывает алгоритм шифрования AES‑256 для ZIP‑элементов. Используйте параметр `EncryptionAlgorithm.Aes256` у каждого `ZipEntry`, чтобы включить AES‑256 шифрование zip. Алгоритм обеспечивает 256‑битную длину ключа, гарантируя, что даже мощные атакующие не смогут подобрать архив без правильного пароля.

## Общие сценарии использования пароля zip для отдельного файла

- **Регуляторное соответствие** – Защищайте медицинские записи или финансовые отчёты индивидуальными паролями перед отправкой аудиторам.
- **Мульти‑тенантные SaaS‑платформы** – Создавайте один архив, содержащий данные каждого арендатора, защищённый паролем, специфичным для арендатора.
- **Скрипты безопасного резервного копирования** – Автоматизируйте ночные резервные копии, где каждый файл зашифрован вращающимся паролем для повышения безопасности.
