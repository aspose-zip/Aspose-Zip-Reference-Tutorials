## 如何在 .NET 中创建无压缩的 Zip 文件？

`ZipArchive` 是表示 zip 容器的类，提供创建、读取和修改 zip 文件的方法。  
`CompressionMethod` 决定条目如何存储；`Store` 选项在不压缩的情况下保存数据。  

将文件加载到 `ZipArchive` 实例中，将每个条目的 `CompressionMethod` 设置为 `Store`，然后保存档案——这就是完整的 “zip file without compression” 工作流，分为三个简明步骤。此方法保持原始文件大小不变，同时仍提供一个可便捷传输或存储的单一容器。

## 为什么在 .NET 中使用 Aspose.Zip 创建 Zip 档案？

Aspose.Zip 在不将整个文件加载到内存的情况下处理高达 **10 GB** 的档案，并支持 **30+** 种压缩方法（包括 Store、Deflate、Bzip2、LZMA、PPMd 和 Enhanced Deflate）。与原生 .NET `System.IO.Compression` 相比，处理大批量文件时归档速度可提升 **最高 2 倍**，同时提供内置加密和 Unicode 文件名支持。

## 常见问题

**Q: 我可以在 .NET Core 上使用 Aspose.Zip 创建 zip archive .net 吗？**  
A: 当然可以。Aspose.Zip 完全支持 .NET Core 2.0–3.1，以及 .NET 5–10。

**Q: 如何在不先解压的情况下修改已有的档案？**  
A: 使用 “modify zip file c#” API——您可以直接在档案流上添加、删除或重命名条目。

**Q: 哪种压缩方法对文本文件的压缩率最佳？**  
A: 通常 Bzip2 或 LZMA 对文本提供更高的压缩率，但速度慢于 Deflate。建议两者都测试，以找到合适的平衡点。

**Q: 创建 zip 档案时是否可以加密文件？**  
A: 可以，Aspose.Zip 支持 AES 加密。您可以在保存前为 ZipArchive 对象设置密码。

**Q: 我需要担心文件名编码吗？**  
A: Aspose.Zip 自动处理 Unicode 文件名，但如果需要兼容旧系统，可显式设置编码。

**Q: 我可以在不重新创建的情况下向已有 zip 添加文件吗？**  
A: 可以，API 提供 **add files zip .net** 方法，直接在现有档案中追加新条目。

**Q: Aspose.Zip 是否支持大文件流式处理？**  
A: 支持。您可以使用流操作，避免将整个文件加载到内存中，这对于大规模场景尤为理想。
