## .NET'te şifreli zip nasıl oluşturulur?

Hedef klasörü yükleyin, bir `ZipFile` nesnesi oluşturun, her dosyayı kendi şifresiyle ekleyin ve sonunda arşivi yazmak için `Save` metodunu çağırın. Bu tüm süreç sadece birkaç satır kod gerektirir ve her girişin belirttiğiniz şifreyle şifrelendiğini garanti eder.

### Adım 1: kaynak dizin yolunu ayarla

Dosyalarınızın bulunduğu kaynak dizinin yolunu tanımlayın.

```csharp
string dataDir = "Your Document Directory";
```

### Adım 2: dosyaları ayrı şifrelerle sıkıştır

Şimdi, dosyaları ayrı şifrelerle sıkıştıralım. Her biri için farklı şifreler kullanarak üç örnek dosya (`alice29.txt`, `asyoulik.txt` ve `fields.c`) kullanacağız.

```csharp
using (FileStream zipFile = File.Open(dataDir + "CompressFilesWithIndividualPasswords_out.zip", FileMode.Create))
{
    FileInfo source1 = new FileInfo(dataDir + "alice29.txt");
    FileInfo source2 = new FileInfo(dataDir + "asyoulik.txt");
    FileInfo source3 = new FileInfo(dataDir + "fields.c");

    using (var archive = new Archive())
    {
        // Compress each file with an individual password
        archive.CreateEntry("alice29.txt", source1, true, new ArchiveEntrySettings(new DeflateCompressionSettings(), new TraditionalEncryptionSettings("pass1")));
        archive.CreateEntry("asyoulik.txt", source2, true, new ArchiveEntrySettings(new DeflateCompressionSettings(), new AesEcryptionSettings("pass2", EncryptionMethod.AES128)));
        archive.CreateEntry("fields.c", source3, true, new ArchiveEntrySettings(new DeflateCompressionSettings(), new AesEcryptionSettings("pass3", EncryptionMethod.AES256)));
        
        // Save the compressed files
        archive.Save(zipFile);
    }
}
```

## Zip dosyalarını dosya başına şifrelerle nasıl şifreleyebilirim?
Arşive eklediğiniz her dosyaya benzersiz bir şifre atayın; Aspose.Zip otomatik olarak her girişe AES‑256 şifrelemesini uygular. Bu yaklaşım, dosya başına erişimi yönetmenizi sağlar ve farklı alıcıların farklı kimlik bilgilerine ihtiyaç duyduğu senaryolarda faydalıdır.

## Zip'i AES‑256 ile nasıl şifreleyebilirim?
`EncryptionAlgorithm.Aes256`, ZIP girişleri için AES‑256 şifreleme algoritmasını belirtir. Her `ZipEntry` üzerinde `EncryptionAlgorithm.Aes256` ayarını kullanarak AES‑256 zip şifrelemesini etkinleştirin. Algoritma 256‑bit anahtar gücü sağlar ve güçlü saldırganların bile doğru şifre olmadan arşivi zorla kırmasını engeller.
