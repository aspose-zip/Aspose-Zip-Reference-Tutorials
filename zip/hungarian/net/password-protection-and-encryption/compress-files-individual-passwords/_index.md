## Hogyan hozhatunk létre zip-et jelszóval .NET-ben?

Töltse be a célmappát, hozzon létre egy `ZipFile` objektumot, adjon hozzá minden fájlt a saját jelszavával, majd végül hívja meg a `Save` metódust az archívum írásához. Ez a teljes folyamat csak néhány kódsort igényel, és garantálja, hogy minden bejegyzés a megadott jelszóval legyen titkosítva.

### 1. lépés: a forráskönyvtár útvonalának beállítása

Adja meg a forráskönyvtár útvonalát, ahol a fájljai találhatók.

```csharp
string dataDir = "Your Document Directory";
```

### 2. lépés: fájlok tömörítése egyedi jelszavakkal

Most tömörítsük a fájlokat egyedi jelszavakkal. Három mintafájlt fogunk használni (`alice29.txt`, `asyoulik.txt` és `fields.c`) mindegyikhez külön jelszóval.

```csharp
using (FileStream zipFile = File.Open(dataDir + "CompressFilesWithIndividualPasswords_out.zip", FileMode.Create))
{
    FileInfo source1 = new FileInfo(dataDir + "alice29.txt");
    FileInfo source2 = new FileInfo(dataDir + "asyoulik.txt");
    FileInfo source3 = new FileInfo(dataDir + "fields.c");

    using (var archive = new Archive())
    {
        // Compress each file with an individual password
        archive.CreateEntry("alice29.txt", source1, true, new ArchiveEntrySettings(new DeflateCompressionSettings(), new TraditionalEncryptionSettings("pass1")));
        archive.CreateEntry("asyoulik.txt", source2, true, new ArchiveEntrySettings(new DeflateCompressionSettings(), new AesEcryptionSettings("pass2", EncryptionMethod.AES128)));
        archive.CreateEntry("fields.c", source3, true, new ArchiveEntrySettings(new DeflateCompressionSettings(), new AesEcryptionSettings("pass3", EncryptionMethod.AES256)));
        
        // Save the compressed files
        archive.Save(zipFile);
    }
}
```

## Hogyan titkosítsuk a zip fájlokat fájlonkénti jelszavakkal?

Minden fájlhoz egyedi jelszót rendeljen, amikor hozzáadja az archívumhoz, és az Aspose.Zip automatikusan alkalmazza az AES‑256 titkosítást minden bejegyzésre. Ez a megközelítés lehetővé teszi a hozzáférés kezelését fájlonként, ami hasznos olyan esetekben, amikor különböző címzetteknek különböző hitelesítő adatokra van szükségük.

## Hogyan titkosítsuk a zip-et AES‑256 használatával?

`EncryptionAlgorithm.Aes256` adja meg az AES‑256 titkosítási algoritmust a ZIP bejegyzésekhez. Használja a `EncryptionAlgorithm.Aes256` beállítást minden `ZipEntry` esetén az AES‑256 zip titkosítás engedélyezéséhez. Az algoritmus 256‑bites kulcserőt biztosít, így még a hatékony támadók sem tudják erőltetve feltörni az archívumot a helyes jelszó nélkül.
